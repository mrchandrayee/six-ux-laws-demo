Recreated from the uploaded 78-second screen recording. The video presents six UX laws through before/after UI comparisons.

## Laws represented
1. Fitts's Law — Big and close wins.
2. Hick's Law — Fewer choices, faster.
3. Chunking — Four slots, not seven.
4. Doherty Threshold — Answer in 400ms.
5. Proximity — Close means together.
6. Von Restorff — Different gets noticed.

## Run
Open `index.html` in a modern browser, or:

```bash
python3 -m http.server 8000
```

Visit http://localhost:8000.

No npm packages, external assets, or API keys required.

## Interactions
- Previous / next law navigation
- Select any law from the field guide
- Keyboard arrow navigation
- Responsive before/after comparison cards

## Source fidelity
The recording is a finished motion-design/UI explainer and does not display its original HTML/CSS/JS source files. This project reconstructs the visible screens and examples as a working interactive web page. Text and law names follow the video; small mock UI details are approximated where the recording is too small to read.
